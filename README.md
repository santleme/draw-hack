## The idea

**Draw uses a webcam and AI to bring sketches on paper into the digital world in real time.** Start with the freedom of a pencil. See your lines captured and interpreted as you draw, then carry that idea toward tools that can shape, model, and test it.

Paper is the fastest place to explore an idea. Draw aims to keep that immediacy while opening a path from a rough sketch to something people can build on.

## How it works

1. **Sketch on paper.** Draw naturally with a pen or pencil.
2. **Capture with a webcam.** Draw watches the page as the sketch takes shape.
3. **Interpret with AI.** The system turns the live drawing into a digital representation.
4. **Take the idea further.** The long-term vision is to bring sketches into CAD and simulation workflows.

## Why Draw

Ideas often begin as a few lines on a page, while the tools for developing them live on a screen. Moving between those worlds can interrupt the creative flow. Draw explores a more direct bridge: keep the paper, add a live digital layer, and make the next step easier.

## The road ahead

Draw is an early-stage project being shaped for a hackathon. **The webcam-and-AI experience is the core direction; CAD and simulation integrations are future goals.** This repository is a monorepo, with the rebuilt website as its first application.

The website brings together three routes: a home page with an archive of consequential drawings and a local sketch pad, an editorial vision page, and a product page.

## Run the website

```sh
npm install
npm run dev
```

The site is served locally by Vite. Its source lives in `apps/site`; shared product packages and integrations can be added as the project grows.

## Project

**Draw** is a technology project exploring how real-time computer vision and AI can connect a physical sketch to digital creation tools.
